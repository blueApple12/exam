## שאלה 2 — 25 נקודות

```c
int examB_q2(int* a, int* b, int n);
```

נתונים a,b באורך n≥1. b ממוין בסדר לא יורד, a אינו בהכרח ממוין. לכל a[i] מקורי, כתבו במקומו את מספר איברי b הקטנים ממנו ממש. החזירו את מספר המיקומים המקוריים ב-a שערכם מופיע לפחות פעם אחת ב-b. אין לשנות את b. ערכי הקלט בין ‎−1000 ל-1000.

דרישת זמן / מקום נוסף: O(n log(n+1)) / O(1)

```c
int examB_q3(char* s, char* p);
```

## שאלה 4 — 25 נקודות

```c
int examB_q4(int* arr, int n);
```

נתון arr באורך n≥1. החזירו את אורך הרצף הרציף הארוך ביותר שעולה ממש. רצף באורך 1 מותר; איברים שווים קוטעים רצף. אין לשנות את arr. הפונקציה עצמה וכל עזר חייבים להיות רקורסיביים; אין לולאות, פונקציית מעטפת או הקצאה דינמית. אין דרישת סיבוכיות.

דרישת זמן / מקום נוסף: No required bound; O(n²) time / O(n) stack
