## שאלה 2 — 25 נקודות

```c
int examB_q2(int* a, int* b, int n);
```

נתונים a,b באורך n≥1, ממוינים בסדר לא יורד, עם ערכים שלמים חיוביים. לכל ערך, הסירו מ-a מספר הופעות השווה למינימום בין מספר הופעותיו ב-a וב-b. כתבו את ההופעות שנותרו בתחילת a בסדר עולה, מלאו את כל יתר התאים באפס והחזירו את מספר ההופעות שנותרו. אין לשנות את b.

דרישת זמן / מקום נוסף: O(n) / O(1)

## שאלה 4 — 25 נקודות

```c
int examB_q4(int* arr, int n);
```

נתון arr באורך n≥1. מיקום i נקרא שיא קידומת אם arr[i] גדול ממש מכל איבר שקדם לו. מיקום 0 תמיד נחשב שיא. החזירו את מספר שיאי הקידומת. אין לשנות את arr. הפונקציה עצמה וכל עזר חייבים להיות רקורסיביים; אין לולאות, פונקציית מעטפת או הקצאה דינמית. אין דרישת סיבוכיות.

דרישת זמן / מקום נוסף: No required bound; O(n²) time / O(n) stack
