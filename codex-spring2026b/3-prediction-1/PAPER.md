## שאלה 2 — 25 נקודות

```c
int examB_q2(int* a, int* b, int n);
```

כל אחד מהמערכים a,b באורך n≥1 מייצג מספר שלם לא שלילי בבסיס עשר, הספרה המשמעותית ביותר ראשונה. כל איבר הוא ספרה 0–9, ואפסים מובילים מותרים. כתבו ל-a את n הספרות האחרונות של הסכום, והחזירו את ספרת הנשא הנוספת (0 או 1). אין לשנות את b. אין להמיר את המערך למספר מטיפוס שלם יחיד.

דרישת זמן / מקום נוסף: O(n) / O(1)

## שאלה 3 — 25 נקודות

```c
int examB_q3(char* s, char* p);
```

נתונה s לא ריקה של אותיות a–z. יש לסדר מחדש את כל תוויה לתוך p כך שלא יהיו שני תווים סמוכים זהים. מבין כל הפתרונות יש לבחור את הקטן ביותר בסדר מילוני. אם יש פתרון, החזירו 1; אחרת החזירו 0 וכתבו מחרוזת ריקה ל-p. אין לשנות את s. יש לסיים את p ב-'\0'.

דרישת זמן / מקום נוסף: O(n) / O(1), fixed 26-letter alphabet

## שאלה 4 — 25 נקודות

```c
int examB_q4(int* arr, int n);
```

נתון arr באורך 1≤n≤2000. החזירו את מספר תתי-המערכים הרציפים באורך לפחות 2 שעולים ממש. תת-מערך באורך 1 אינו נספר. אין לשנות את arr. הפונקציה עצמה וכל עזר חייבים להיות רקורסיביים; אין לולאות, פונקציית מעטפת או הקצאה דינמית. אין דרישת סיבוכיות.
