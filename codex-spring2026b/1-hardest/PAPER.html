void f1(int n){
 for(int i=1;i<=n;i*=2)
  for(int j=0;j<n;j+=i)
   for(int k=0;k<i;k++) printf("*");
}

int f2(int n){

 int* p=malloc(n*n*sizeof(int));
 int x=f2(n/2);
 int y=f2(n/2);

שאלה 2 — 25 נקודות

נתונים שני מערכים a,b באורך n≥1. כל איברי b שונים והוא התקבל מסיבוב מעגלי של מערך ממוין בסדר עולה ממש. לכל איבר מקורי a[i], יש לכתוב במקומו את הערך ב-b שמרחקו ממנו מינימלי; בשוויון בחרו בערך הקטן יותר. החזירו את מספר האיברים המקוריים של a שהופיעו ב-b. אין לשנות את b. כל ערכי הקלט בין ‎−1000 ל-1000. כל n התאים של a הם חלק מהתוצאה.

O(n log(n+1)) / O(1)

שאלה 3 — 25 נקודות

נתונה מחרוזת s לא ריקה של אותיות a–z. כתבו ל-p את תת-הסדרה המינימלית בסדר מילוני שמכילה כל אות שונה של s פעם אחת בדיוק. תת-סדרה שומרת על סדר ההופעה, אך רשאית לדלג על תווים. החזירו את אורך p. אין לשנות את s. יש לסיים את p ב-'\0'.

O(n) / O(1), alphabet size 26; p is output

שאלה 4 — 25 נקודות

נתון arr באורך 1≤n≤2000. החזירו את מספר הזוגות i<j שעבורם arr[i]>arr[j]. מותר לשנות את arr. כל איבר בין ‎−1000 ל-1000. הפונקציה עצמה וכל פונקציות העזר חייבות להיות רקורסיביות; אין לולאות, פונקציית מעטפת או הקצאה דינמית. אין דרישת סיבוכיות בשאלה זו. שוויון אינו נחשב היפוך.

No required bound; supplied solution O(n²) time / O(n) stack
