## שאלה 2 — 25 נקודות

```c
int examB_q2(int* a, int* b, int n);
```

נתונים a,b באורך n≥1, ממוינים בסדר לא יורד, עם ערכים שלמים חיוביים. כתבו בתחילת a את החיתוך עם ריבוי של שני המערכים, בסדר עולה: כל ערך יופיע כמספר הפעמים המינימלי שלו בשני הקלטים. החזירו את אורך החיתוך k ומלאו באפס את כל a[k..n−1]. אין לשנות את b.

דרישת זמן / מקום נוסף: O(n) / O(1)

## שאלה 3 — 25 נקודות

```c
int examB_q3(char* s, char* p);
```

נתונה s לא ריקה של אותיות a–z. כתבו ל-p תו אחד מכל רצף מקסימלי של תווים זהים ברציפות. החזירו את מספר התווים שנמחקו, ולא את האורך החדש. אין לשנות את s; יש לסיים את p ב-'\0'. אין למחוק הופעות נפרדות שאינן באותו רצף.

דרישת זמן / מקום נוסף: O(n) / O(1)

## שאלה 4 — 25 נקודות

```c
int examB_q4(int* arr, int n);
```

נתון arr באורך n≥1. החזירו 1 אם המערך פלינדרומי, ו-0 אחרת. אין לשנות את המערך. הפונקציה עצמה חייבת להיות רקורסיבית. אסורות לולאות, פונקציית מעטפת והקצאה דינמית; גם עזר חייב להיות רקורסיבי. אין דרישת סיבוכיות.
